# Subtemas: HikCentral Professional (nivel inicial a intermedio, técnicos instaladores y de soporte)

Armado a partir de cómo enseña Hikvision el producto (certificación HCSA/HCSP y cursos HikCentral de la Hikvision Academy, guía "HCP Training - Beginners Guide" del soporte de Hikvision USA, índice del manual del Web Client V2.6.1 y Quick Start Guide) y de los temas que piden los foros y el FAQ oficial.

- T01 Familia HikCentral y dónde encaja Professional (Lite, Access Control, Connect, FocSign solo para ubicar)
- T02 Arquitectura: SYS, Streaming Gateway / Streaming Server, Web Client, Control Client, Mobile Client, servidores de grabación
- T03 Requisitos de servidor, dimensionamiento y virtualización
- T04 Instalación: paquetes, modo típico y personalizado, Service Manager, primer ingreso del admin
- T05 Licenciamiento: base y expansión, activación online y offline, desactivación y cambio de hardware, errores de licencia
- T06 Alta de dispositivos: IP/dominio, Hik-Connect DDNS, ISUP (Device ID), ONVIF
- T07 Áreas, recursos y vistas (incluye mapas E-map y GIS)
- T08 Grabación: en el dispositivo vs. central (pStor, Hybrid SAN, Cloud Storage), plantillas de grabación
- T09 Eventos y alarmas: disparadores, acciones vinculadas, destinatarios, horarios de recepción
- T10 Control de acceso: personas, credenciales, niveles de acceso, plantillas de horario, aplicar a dispositivos
- T11 Tiempo y asistencia: puntos de control, reglas, turnos, reportes
- T12 Mapas: E-map vs. GIS, puntos calientes
- T13 Roles, usuarios y seguridad de cuentas (contraseñas, HTTPS)
- T14 Backup y restauración de datos del sistema, base de datos
- T15 Puertos, NAT y acceso remoto (WAN)
- T16 Troubleshooting: dispositivo offline, streaming, servicios, errores de login y de licencia
