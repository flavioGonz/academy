# Lección 6. Elegir detector

**Escuchá:** elegir-detector.mp3 (2 min)

**La idea, en tres líneas**
- Se elige en dos pasos: primero el riesgo de fuego del lugar, después los fenómenos que no son fuego (vapor, polvo, aerosol, cocina), y se deja escrito el porqué.
- AVENAR detector 4000 tiene nueve variantes: térmico FAH-425-T-R, ópticos FAP-425-O y O-R, doble óptico DO-R, multisensores OT, OT-R, DOT-R, DOTC-R y DOTCO-R (con CO). No existe un "AVENAR detector 5000" en las fuentes de Bosch.
- El firmware 4.8 es el último que soporta la serie 400 (O400, OT400, OC410, OTC410, T400): conviene relevar antes de actualizar.

**Impacto:** menos falsas alarmas desde el diseño y un mantenimiento que entiende por qué cada detector está donde está.

**Quién lo dice:** 4 de 5 fuentes van por el método de dos pasos (FIA, columna sobre BS 5839, web y hoja de datos de Bosch); el resumen del estudio BRE en pbctoday empuja al multisensor como mejor opción general contra falsas alarmas.

**Laboratorio** · Rápido · 10 min
Completá la tabla con cinco ambientes reales:
```text
Ambiente            | Riesgo de fuego     | Fenómenos engañosos | Detector       | Porqué
Habitación hotel    | latente (tapizados) | vapor, aerosol      | FAP-425-DOTC-R | CO rechaza vapor
Sala de tableros    |                     |                     |                |
Depósito con polvo  |                     |                     |                |
Cocina en servicio  |                     |                     |                |
Oficina             |                     |                     |                |
```
Referencias de la hoja de datos: el térmico dispara por máximo de 54 °C o 69 °C o por gradiente; el sensor de CO también reacciona a hidrógeno y monóxido de nitrógeno.
⚠️ El tipo de detector de cada ambiente lo define el proyecto firmado; si tu tabla no coincide, se consulta, no se cambia en obra.

**Regla para quedarse**
Cada detector instalado tiene su porqué escrito: riesgo, fenómeno engañoso y modelo.
